Requirements

Jellyfin Server 12.0 and Apple OS 27 are the only supported versions. The app currently runs on iPhone, iPad, and Mac.

Try the app

Public TestFlight links are planned for the coming weeks. We'll add the link here when it is available.

What's next

CarPlay is coming soon for VelaCanto. An Apple TV app is planned for later in 2026. These are upcoming additions, not features available today.

Support for other media services and a web experience are planned. Neither is supported today.

Privacy

No automatic app analytics or debug reporting. Debug information can be shared explicitly. TestFlight builds include basic TestFlight feedback reporting.
